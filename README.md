# Online Library Backend

Node.js + Express API for Online Library audiobook system.

## Setup

### Install dependencies
\`\`\`bash
cd backend
npm install
\`\`\`

### Environment variables
Copy `.env.example` to `.env`

### Database
PostgreSQL is running in Docker

### Start server
\`\`\`bash
# Development
npm run dev

# Production
npm start
\`\`\`
